# Design

## Theme

Reliable financial utility. Neutral gray canvas, white surfaces, restrained teal accent. Calm and institutional, not consumer-app flashy.

## Color palette

| Token | Value | Use |
|-------|-------|-----|
| Teal | `#0F766E` | Primary actions, links, brand mark |
| Teal Deep | `#115E59` | Hover / pressed, savings emphasis |
| Teal Soft | `#ECFDF5` | Selected rows, info banners |
| Background | `#F5F6F8` | Page canvas (neutral gray) |
| Surface | `#FFFFFF` | Cards, inputs, panels |
| Ink | `#111827` | Body text |
| Muted | `#6B7280` | Secondary copy |
| Border | `rgba(17,24,39,0.1)` | Neutral dividers (not tinted) |

## Rationale

- **Neutral borders** — structure reads as tool chrome, not marketing.
- **Teal accent** — common in banking/health tools; trustworthy without bright SaaS blue.
- **Low saturation** — reduces “startup demo” feel.

## Typography

System UI stack. Sentence-case labels. Fixed rem scale.

## Components

White panels, 1px neutral borders, teal primary buttons, flat shadows.
